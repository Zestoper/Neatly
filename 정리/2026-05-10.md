# 2026-05-10

## 프로젝트 개요

Neatly — Notion과 유사한 문서 중심 정리 도구.
이모티콘 없는 깔끔한 UI, 한 단계씩 진행.

---

## 기술 스택

- 백엔드: FastAPI, SQLAlchemy, MySQL, JWT (python-jose), bcrypt
- 프론트엔드: React, TypeScript, Vite, axios, react-router-dom

---

## 구현 내용

### 1. DB 모델 (models.py)

**User 테이블**
- id: UUID (CHAR 36, 자동 생성)
- email: 고유값, 필수
- password_hash: bcrypt 해시 저장
- plan: FREE / STANDARD / PREMIUM (기본값 FREE)
- created_at, updated_at: 자동 시간 기록

**Document 테이블**
- id: UUID (자동 생성)
- user_id: User 테이블 외래키
- title: 문서 제목
- raw_text: 문서 본문 (Text 타입)
- status: UPLOADED / PROCESSING / DONE / FAILED (기본값 DONE)
- created_at: 자동 시간 기록

---

### 2. 인증 (routers/auth.py, routers/users.py)

**회원가입 — POST /register**
- 이메일 중복 확인
- bcrypt로 비밀번호 해시 후 저장
- 생성된 사용자 id, email 반환

**로그인 — POST /auth/login**
- 이메일로 사용자 조회
- bcrypt로 비밀번호 검증
- JWT 액세스 토큰 발급 (유효시간 60분, HS256 알고리즘)

**내 정보 조회 — GET /auth/me**
- Authorization 헤더의 Bearer 토큰 검증
- 현재 로그인된 사용자의 id, email, plan 반환

---

### 3. 문서 (routers/documents.py)

**문서 목록 조회 — GET /documents**
- JWT 인증 필수
- 현재 로그인한 사용자의 문서만 필터링해서 반환

**문서 생성 — POST /documents**
- JWT 인증 필수
- title, summary(raw_text)를 받아 DB에 저장
- 생성된 Document 객체 반환

---

### 4. AI 요약 (routers/ai.py)

**POST /ai/summarize**
- content를 받아 요약 결과 반환
- 현재는 앞 50자 + "..." 반환하는 임시 구현 (실제 AI 연동 예정)

---

### 5. 프론트엔드

**라우팅 (App.tsx)**
- / : 대시보드 (로그인 필수)
- /login : 로그인 페이지
- /register : 회원가입 페이지
- ProtectedRoute: 토큰 없으면 /login으로 강제 이동

**API 통신 (api/)**
- client.ts: axios 인스턴스, baseURL http://localhost:8000
- auth.ts: 로그인, 내 정보 조회
- users.ts: 회원가입
- documents.ts: 문서 목록 조회, 문서 생성
- ai.ts: AI 요약 요청

**페이지 (pages/)**
- Login.tsx: 이메일/비밀번호 입력, 로그인 성공 시 token을 localStorage에 저장
- Register.tsx: 회원가입 후 /login으로 이동
- Dashboard.tsx: 내 정보 표시, 문서 생성, AI 요약, 문서 목록 출력, 로그아웃

**컴포넌트 (components/)**
- Header.tsx: 상단 헤더
- Sidebar.tsx: 좌측 네비게이션 (Dashboard, Documents, Emails, Insights, Settings)
- SummaryCard.tsx: 제목·값 카드 컴포넌트 (재사용 가능)
- ProtectedRoute.tsx: 인증 가드
