# 이메일 자동 동기화 (Premium)

## 어떤 기능인가?

Premium 플랜 사용자의 Gmail을 **15분마다 자동으로 확인**해서
아직 문서로 저장되지 않은 새 이메일을 자동으로 AI 요약 후 문서로 변환합니다.

또한 Emails 페이지 상단에 **"지금 동기화"** 버튼이 생겨서 수동으로 즉시 실행할 수 있습니다.

---

## 동작 원리

```
[15분마다 / 버튼 클릭]
       ↓
Gmail API 호출 (마지막 동기화 시각 이후 메일만)
       ↓
이미 변환된 문서 제목과 비교 → 새 것만 선별
       ↓
Groq AI로 요약 생성
       ↓
Document 테이블에 저장 (raw_html, sender 포함)
       ↓
user.gmail_last_sync 업데이트
```

### `backend/routers/email_sync.py`

```python
def sync_user_emails(user: User, db: Session) -> int:
    """
    핵심 동기화 함수.

    1. gmail_last_sync 이후 메일만 쿼리 (after:{timestamp} Gmail 검색어)
       - 처음 동기화라면 오늘 자정 이후 메일만 가져옴 (과부하 방지)
    2. 이미 변환된 문서 제목 목록 캐시 → 새 메일만 선별
    3. Groq AI로 요약 → Document에 저장
    4. gmail_last_sync 갱신
    """
    ...

# POST /emails/sync — 수동 즉시 동기화 (Premium 전용)
@router.post("/emails/sync")
def manual_sync(...):
    count = sync_user_emails(current_user, db)
    return {
        "synced": count,            # 새로 저장된 문서 수
        "last_sync": ...,           # 동기화 완료 시각
    }

# GET /emails/sync/status — 마지막 동기화 시각 조회
@router.get("/emails/sync/status")
def sync_status(...):
    return {"last_sync": current_user.gmail_last_sync}
```

### `backend/scheduler.py`

```python
from apscheduler.schedulers.background import BackgroundScheduler
from apscheduler.triggers.interval import IntervalTrigger

scheduler = BackgroundScheduler()

def sync_all_premium_emails():
    """
    15분마다 실행.
    Gmail이 연결된 Premium 사용자를 모두 순회하며 sync_user_emails() 호출.
    각 사용자별로 독립적인 DB 세션 사용.
    """
    ...

scheduler.add_job(
    sync_all_premium_emails,
    trigger=IntervalTrigger(minutes=15),
    id="email_sync",
    replace_existing=True,  # 중복 등록 방지
)
```

## DB 변경

`User` 테이블에 컬럼 추가:

```sql
ALTER TABLE User ADD COLUMN gmail_last_sync DATETIME NULL;
```

`models.py`:
```python
gmail_last_sync = Column(DateTime, nullable=True)
# 마지막 자동 동기화 시각 — 이후 이메일만 가져오는 데 사용
```
