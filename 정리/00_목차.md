## 새로 생긴 파일 목록

### 백엔드
- `backend/routers/search.py` — 전체 검색 API
- `backend/routers/briefing.py` — 브리핑 생성/조회 API
- `backend/routers/email_sync.py` — 이메일 동기화 API
- `backend/scheduler.py` — APScheduler 백그라운드 작업 관리

### 프론트엔드
- `my-app/src/pages/Search.tsx` — 검색 페이지
- `my-app/src/pages/Search.module.css` — 검색 페이지 스타일
- `my-app/src/api/search.ts` — 검색 API 클라이언트
- `my-app/src/api/briefing.ts` — 브리핑 API 클라이언트
- `my-app/src/api/emailSync.ts` — 동기화 API 클라이언트
