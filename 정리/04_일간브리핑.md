# AI 일간 브리핑 (Premium)

## 어떤 기능인가?

오늘 추가된 모든 문서와 이메일을 AI가 분석해서
**핵심 요약 + 주요 항목 + 할 일 제안**을 하나의 브리핑 문서로 만들어 줍니다.

- **매일 오전 9시 자동 생성** (APScheduler)
- Dashboard에서 **"오늘 브리핑 생성"** 버튼으로 수동 실행 가능
- 브리핑 결과는 `Documents` 목록에도 `"AI 일간 브리핑 — YYYY년 MM월 DD일"` 문서로 저장됨
- 오늘 브리핑을 다시 생성하면 기존 내용을 **덮어씀** (중복 방지)
