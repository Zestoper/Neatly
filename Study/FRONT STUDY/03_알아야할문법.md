### 옵셔널 체이닝과 nullish coalescing

```typescript
// ?. — null/undefined이면 오류 대신 undefined 반환
error.response?.status         // response가 없어도 오류 안 남
meData.data?.gmail_access_token

// ?? — null 또는 undefined일 때만 기본값 사용
localStorage.getItem("plan") ?? "FREE"   // "" (빈 문자열)은 통과
res.last_sync ?? null

// || — falsy(0, "", false, null, undefined)이면 기본값
```

### useCallback과 useMemo

```typescript
// useCallback — 함수 참조 고정 (불필요한 리렌더 방지)
const showToast = useCallback((message: string) => {
    setToasts(prev => [...prev, { id: Date.now(), message }]);
}, []);  // 의존성 없으면 마운트 시 한 번만 생성

// useMemo — 계산 결과 캐시
const recentDocs = useMemo(() =>
    documents.sort(...).slice(0, 3),
[documents]);  // documents가 바뀔 때만 재계산
```

## 비동기 처리

### async / await

```typescript
const handleSync = async () => {
    setSyncing(true);
    try {
        const res = await syncEmails();     // Promise 완료 대기
        setLastSync(res.last_sync ?? null);
        showToast("동기화 완료");
    } catch (err: any) {
        showToast(err.response?.data?.detail ?? "오류 발생");
    } finally {
        setSyncing(false);  // 성공/실패 모두 실행
    }
};
```

### Promise.all — 병렬 호출

```typescript
// 순차 — 느림 (총 시간 = A + B)
const docsData = await getDocuments();
const meData = await api.get("/auth/me");

// 병렬 — 빠름 (총 시간 = max(A, B))
const [docsData, meData] = await Promise.all([
    getDocuments(),
    api.get("/auth/me"),
]);
```
