## Python 기초

### yield와 제너레이터

```python
def get_db():
    db = SessionLocal()
    try:
        yield db       # 여기서 잠시 멈추고 db를 바깥에 넘김
    finally:
        db.close()     # 바깥 코드가 끝나면 여기서 재개
```

- `yield`가 있는 함수는 제너레이터입니다.
- FastAPI의 `Depends(get_db)`가 제너레이터를 받으면 요청 처리 전에 `yield`까지 실행하고, 요청이 끝나면 `finally`를 실행합니다.
- 이 패턴 덕분에 DB 연결이 예외 발생 시에도 반드시 닫힙니다.

### async / await

```python
async def connect(self, room_id: str, ws: WebSocket, ...):
    await ws.accept()         # accept가 완료될 때까지 대기
    await ws.send_json(data)  # 전송 완료될 때까지 대기
```

- `async def` : 코루틴 함수. 일반 함수처럼 호출할 수 없고 `await`로 실행해야 합니다.
- `await` : 해당 작업이 완료될 때까지 현재 코루틴을 일시 중단하고 다른 코루틴을 실행합니다.
- WebSocket처럼 I/O 대기가 많은 경우 비동기가 효율적입니다.

## Pydantic

```python
from pydantic import BaseModel, EmailStr

class LoginRequest(BaseModel):
    email: EmailStr   # @가 없으면 422 자동 반환
    password: str

class AskRequest(BaseModel):
    question: str
    history: list[HistoryMessage] = []  # 기본값 설정 가능
```

- `BaseModel`을 상속받으면 FastAPI가 요청 바디를 자동으로 파싱하고 유효성 검사합니다.
- `EmailStr` : 이메일 형식 자동 검증
- 유효성 검사 실패 시 `422 Unprocessable Entity`를 자동으로 반환합니다.

## SQLAlchemy

### 기본 쿼리 패턴

```python
# 단일 조회
user = db.query(User).filter(User.id == user_id).first()

# 목록 조회
docs = db.query(Document).filter(
    Document.user_id == user.id,
    Document.deleted_at == None,

# IN 쿼리
rows = db.query(DocumentTag, Tag).filter(
    DocumentTag.document_id.in_(doc_ids)

# 삽입
db.add(Document(...))
db.flush()   # ID 생성만, 커밋은 아직 안 함
db.commit()

# 수정

db.commit()

# 삭제 (벌크)
```

### 모델 정의

```python
from sqlalchemy import Column, String, Enum, DateTime, ForeignKey, Text, Index
from sqlalchemy.ext.declarative import declarative_base

Base = declarative_base()

class Document(Base):
    __tablename__ = "Document"
    __table_args__ = (
        Index("ix_document_user_deleted", "user_id", "deleted_at"),  # 복합 인덱스
    )

    id      = Column(String(36), primary_key=True, default=lambda: str(uuid.uuid4()))
    user_id = Column(String(36), ForeignKey("User.id"))
    status  = Column(Enum('DONE', 'FAILED', name='document_status'), default='DONE')
    # name= 파라미터 : PostgreSQL에서 Enum 타입명을 명시해 충돌 방지
```

## FastAPI 라우터 패턴

```python
from fastapi import APIRouter, Depends, HTTPException

router = APIRouter()

@router.post("/emails/sync")
def manual_sync(
    db: Session = Depends(get_db),
    current_user: User = Depends(get_current_user),
):
    if current_user.plan != "PREMIUM":
        raise HTTPException(status_code=403, detail="Premium 플랜에서 사용할 수 있습니다.")
    ...
    return {"synced": count, "last_sync": current_user.gmail_last_sync}
```

- `HTTPException` : status_code와 detail 메시지로 에러를 반환합니다.
- 반환값은 Pydantic 모델 또는 dict로 자동으로 JSON 직렬화됩니다.

## 예외 처리 패턴

```python
try:
    refresh_if_expired(creds, user, db)
except Exception:
    return 0  # 어떤 예외든 0 반환 (silent fail)

# 특정 예외만
try:
    ...
except JWTError:
    raise HTTPException(status_code=401, detail="인증 실패")
```

- 백엔드에서 `except Exception`으로 모든 예외를 잡으면 silent fail이 발생할 수 있습니다. 디버깅이 어려워지므로 로그를 남기거나, 꼭 필요한 경우에만 씁니다.
